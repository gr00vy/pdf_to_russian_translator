# PDF Translator — перевод с английского на русский

Переводит **любой** PDF-документ с английского языка на русский одним кликом в Проводнике Windows или одной командой в Linux/macOS. Сохраняет исходную разметку и форматирование максимально близко к оригиналу.

## Возможности

- **Пакетный перевод** — группирует несколько фрагментов текста в один запрос к API, что позволяет избежать ограничений Google на частоту запросов
- **Умное масштабирование шрифта** — определяет исходный размер шрифта (заголовки остаются крупными), уменьшает его только тогда, когда русский текст шире английского оригинала
- **Перенос с учётом пикселей** — измеряет реальную отображаемую ширину кириллических символов, чтобы текст не вылезал на соседние строки
- **API-ключ не нужен** — использует `googletrans` (бесплатный Google Translate)

## Предварительные требования: установка Python

### Windows

1. Скачайте Python 3.9 или новее с <https://www.python.org/downloads/>
2. Запустите установщик
3. **Важно:** на первом экране поставьте галочку **"Add Python to PATH"** — это необходимо для работы программы
4. Нажмите "Install Now" и дождитесь завершения установки

Чтобы проверить установку, откройте Командную строку (`Win + R` → введите `cmd`) и выполните:
```
python --version
```
Вы должны увидеть что-то вроде `Python 3.9.x` или новее.

### Linux / macOS

На большинстве систем Python уже установлен. Проверьте командой:
```bash
python3 --version
```
Если нужно установить:

- **Ubuntu/Debian:** `sudo apt update && sudo apt install python3 python3-venv`
- **Fedora/RHEL:** `sudo dnf install python3`
- **macOS (Homebrew):** `brew install python`

## Быстрый старт

### Windows

1. **Установка зависимостей:** дважды щёлкните по файлу `create_virtual_environment.bat` — откроется окно, дождитесь завершения
2. **Перевод файла:** дважды щёлкните по `pdf_translate.bat`, затем введите путь к вашему PDF (или перетащите файл)
3. *(Опционально)* Добавление контекстного меню: дважды щёлкните по `install_pdf_context_menu.bat` — после этого при нажатии правой кнопкой мыши на любой `.pdf` появится пункт **"Translate PDF to Russian"**

### Linux / macOS

1. **Установка зависимостей:** выполните `bash create_virtual_environment.sh`
2. **Перевод файла:** выполните `./pdf_translate.sh your_document.pdf`
3. Результат будет сохранён как `your_document_ru.pdf` (или укажите своё имя: `./pdf_translate.sh input.pdf output.pdf`)

---

## Удаление контекстного меню (Windows)

Если вы добавили пункт в контекстное меню Проводника и хотите его удалить, дважды щёлкните по **`uninstall_pdf_context_menu.bat`**. Это удалит запись "Translate PDF to Russian" из Проводника Windows. Никакие файлы не удаляются — очищаются только записи реестра.

---

## Именование выходного файла

Если указать только один аргумент (исходный файл), к имени результата добавится суффикс `_ru`:

```
input.pdf          →  input_ru.pdf
my_report.pdf      →  my_report_ru.pdf
```

Также можно задать произвольное имя результата:
```bash
python pdf_translate.py input.pdf translated_output.pdf
```

---

## Как это работает

1. Извлекает весь текст из PDF вместе с данными о позиции и размере шрифта
2. Группирует фрагменты в пакеты по ~20 элементов, оборачивает каждый в уникальный маркер (`§TX0001§Hello world`)
3. Отправляет каждый пакет как **один** запрос на перевод к Google Translate
4. Распаковывает переведённый ответ по идентификаторам маркеров
5. Удаляет исходный английский текст и накладывает русский перевод в ту же позицию с адаптированным размером шрифта

## Требования

- Python 3.9+ (см. инструкции по установке выше)
- Все остальные зависимости устанавливаются автоматически во внутреннюю среду `.venv` — никаких системных изменений не требуется
